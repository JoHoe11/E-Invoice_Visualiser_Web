# E-Invoice_Visualiser_Web

Visualizes E-Invoices of both UBL and CII invoices. It cannot display ZugPferd because it already has a PDF so duh. Only .xml files can be visualized.

## Features

*   Visualizes UBL and CII E-Invoices.
*   Accepts only .xml file inputs.
*   Web-based interface for easy access.

## Tech Stack / Key Dependencies

*   JavaScript
*   CSS
*   HTML
*   Vite
*   Next.js
*   TypeScript


## Prerequisites

*   Node.js (version >= 22.14.1 recommended)
*   npm or yarn package manager

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/JoHoe11/E-Invoice_Visualiser_Web
    cd E-Invoice_Visualiser_Web
    ```
2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

## Usage / Getting Started

1.  Run the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    ```
2.  Build the project:
    ```bash
    npm run build
    # or
    yarn build
    ```
3.  Preview the build:
     ```bash
     npm run preview
     # or
     yarn preview
     ```
